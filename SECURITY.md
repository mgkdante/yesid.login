# Security

This code runs a live sign-in service for real people. Please report a vulnerability privately, never in a public issue or pull request.

- Preferred: GitHub's private vulnerability reporting, under this repository's **Security** tab.
- Or email contact@yesid.dev with "Security" in the subject.

Please include what you found, how to reproduce it, and what an attacker could do with it. Do not test against login.yesid.dev with accounts or data that are not yours, and do not try to read other people's data or degrade the service. Testing a local copy is welcome.

There is no bug bounty. I will acknowledge your report, keep you informed, and credit you when the fix ships if you wish.
